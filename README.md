# Documentation checks for Python AI projects

Setup instructions should work as written. I check selected examples against a specific source revision, record the result, and prepare focused corrections.

This service is provided by [MaxKerkula](https://github.com/MaxKerkula). The work uses AI assistance and recorded local checks.

## Start with a $25 pilot

For one public Python project, we agree on up to three setup or API documentation pages and one environment. The pilot includes a findings report, reproducible commands, and one small documentation correction where a defect is confirmed.

The pilot covers up to one hour of work. The report states what was checked, what failed, and what could not be checked within the agreed scope. A correction is limited to one issue and 100 changed lines. Application code changes require a separate quote.

## Continue for $79 per month

After an accepted pilot, the monthly service includes two reviews of the same agreed pages, a change report, and up to two small documentation corrections. Total work is limited to two hours per month, including one revision per correction. Work beyond that limit requires a separate agreement.

This is an optional monthly service. There is no automatic enrollment or charge. We agree on the work and delivery dates before each service period. There is no continuous monitoring or emergency support.
